# Phase 12 — Shipment State Machine

## States & Independence
WatchStore strictly separates **OrderStatus**, **FulfilmentStatus**, **ShipmentStatus**, **PaymentStatus**, and **InventoryReservation.status**. Shipment tracking or RTO events never modify `Payment.status`, initiate refunds, or restore `InventoryReservation` stock.

## Allowed Transitions (`shipment-state-machine.ts`)
- `PENDING` -> `SERVICEABILITY_CHECKED`, `SHIPMENT_CREATED`, `AWB_ASSIGNED`, `IN_TRANSIT`, `CANCELLED`, `FAILED`, `RECONCILIATION_REQUIRED`
- `SHIPMENT_CREATED` -> `AWB_ASSIGNED`, `CANCELLED`, `FAILED`, `RECONCILIATION_REQUIRED`
- `AWB_ASSIGNED` -> `PICKUP_SCHEDULED`, `PICKUP_COMPLETED`, `IN_TRANSIT`, `CANCELLED`, `FAILED`, `RECONCILIATION_REQUIRED`
- `PICKUP_SCHEDULED` -> `PICKUP_COMPLETED`, `IN_TRANSIT`, `OUT_FOR_DELIVERY`, `DELIVERED`, `CANCELLED`, `RTO_INITIATED`, `RECONCILIATION_REQUIRED`
- `PICKUP_COMPLETED` -> `IN_TRANSIT`, `OUT_FOR_DELIVERY`, `DELIVERED`, `RTO_INITIATED`
- `IN_TRANSIT` -> `OUT_FOR_DELIVERY`, `DELIVERED`, `RTO_INITIATED`
- `OUT_FOR_DELIVERY` -> `DELIVERED`, `IN_TRANSIT`, `RTO_INITIATED`
- `RTO_INITIATED` -> `RTO_DELIVERED`
- `DELIVERED`, `RTO_DELIVERED`, `CANCELLED` -> *(Terminal)*
- `RECONCILIATION_REQUIRED` -> `SHIPMENT_CREATED`, `AWB_ASSIGNED`, `PICKUP_SCHEDULED`, `IN_TRANSIT`, `DELIVERED`, `CANCELLED`, `FAILED`
